# WrapPin 1.0.21 Build 72：快捷指令自动化

新增「准备收藏点自动化」与「等待收藏点模拟」，支持按连接状态切换蜂窝、打开飞书、等待五秒后恢复真实位置。完整流程文件及说明见 [快捷指令文档](../../Documentation/favourite-feishu-shortcut.md)。

本目录的 IPA 为未签名 Release 包，不能直接安装。请使用原有 SideStore 或其他签名方式；隧道版签名需要覆盖主 App 和 Packet Tunnel 扩展。不要为了安装删除已有 App 或配对数据。

## 真机验收

1. 使用对应版本的已签名 App 覆盖安装，确认关于页面为 Build 72。
2. 配对并至少保存一个收藏点，导入对应的 `.shortcut` 文件。
3. 运行快捷指令，确认收藏点可以选择，蜂窝开关与连接阶段一致。
4. 确认模拟成功才打开飞书，停留五秒后返回 WrapPin 并停止模拟。
5. 核对失败分支：等待失败后仍开启蜂窝，跳过飞书并停止连接。
6. 若手动取消或系统中断，手动重新开启蜂窝并运行恢复真实位置。

## 验证范围

Release 归档、IPA 完整性、版本与动作元数据、离线自动化分支和本地化检查已验证。实际蜂窝切换、手机导入快捷指令及跨 App 流程尚未完成真机验收。
